# ระบบสร้างภาพพร้อม QR Code หลายหน้า (Batch QR Generator on Image)

เว็บแอปพลิเคชันสำหรับวาง QR Code และข้อความใต้ภาพลงบนภาพต้นแบบ (โปสเตอร์/แบนเนอร์) โดยสามารถคลิกลากย้ายตำแหน่งและปรับขนาดได้อย่างอิสระ พร้อมระบบจัดการข้อมูลแบบกลุ่ม (Batch Data) และสั่งพิมพ์หลายหน้าได้ทันที

---

## ฟีเจอร์หลัก (Key Features)

1. **คลิกลากจัดตำแหน่งและปรับขนาด (Drag & Resize)**:
   - คลิกลาก QR Code ไปวางตรงตำแหน่งใดก็ได้บนภาพแบบเรียลไทม์
   - ลากปุ่มมุมขวาล่างของ QR Code เพื่อย่อ/ขยายขนาด
   - ปรับตำแหน่งแบบละเอียดด้วยปุ่มลูกศรบนคีย์บอร์ด (Arrow Keys / Shift + Arrow Keys)
   - ปุ่มจัดกึ่งกลางแนวนอน/แนวตั้งในคลิกเดียว
   - ปุ่มจัดตำแหน่งเริ่มต้นตามตัวอย่าง 24CHARGE

2. **ปรับแต่งการ์ดและข้อความใต้ QR Code**:
   - เลือกใส่พื้นหลังการ์ดสีขาวโค้งมน หรือโปร่งใส
   - ปรับขนาดตัวอักษร, สี, แบบอักษร (Prompt, Kanit, Sarabun, Inter), ความหนา
   - ปรับระยะห่างระหว่าง QR Code และข้อความ

3. **ระบบจัดการชุดข้อมูล (Batch Data)**:
   - รองรับการคัดลอก (Copy) ข้อมูลจาก Microsoft Excel หรือ Google Sheets แล้ววาง (Paste) ได้ทันที
   - มีข้อมูลเริ่มต้น 20 รายการตามตัวอย่างของ 24CHARGE
   - เครื่องมือสร้างลำดับอัตโนมัติ (Sequence Generator) สามารถสร้างรหัสต่อเนื่องได้ไม่จำกัด เช่น 1 ถึง 100

4. **การสั่งพิมพ์และส่งออกหลายหน้า (Multi-page Print & Export)**:
   - **พิมพ์ทั้งหมด (Print All)**: พิมพ์ออกเครื่องพิมพ์ผ่านเบราว์เซอร์ โดยแต่ละหน้าจะแยก 1 ภาพต่อ 1 หน้ากระดาษพอดี
   - **ดาวน์โหลด PDF**: บันทึกทุกหน้ารวมเป็นไฟล์ PDF เดียวความละเอียดสูง
   - **ดาวน์โหลด ZIP**: บันทึกรูปภาพทุกหน้าเป็นไฟล์ `.png` ความละเอียดสูง บรรจุในไฟล์ ZIP
   - **ดาวน์โหลดหน้านี้**: บันทึกเฉพาะหน้าที่กำลังดูอยู่เป็นภาพ PNG

---

## วิธีเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `start.bat`
เพียงดับเบิลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์นี้ ระบบจะเปิดเว็บเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:3000`

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```bash
cd "d:\Create QR code"
npm run dev
```
แล้วเปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
